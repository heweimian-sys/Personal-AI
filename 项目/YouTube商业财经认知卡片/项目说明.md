# YouTube 海外商业与财经认知卡片制作系统 V1

面向 22～35 岁中文读者，围绕普通人的财富与商业认知，把可追溯的海外内容编辑为手机知识轮播。栏目：财富与商业逻辑、真实副业与创业案例、职场能力、投资理财基础。

## 当前实现边界

这是仓库内的独立 Python 项目，不是已经上线的网站。程序负责公开文字页面/元数据/可访问字幕获取、文字稿导入、证据字段检查、图片渲染与几何质检；研究员（Codex）负责选题、事实核查、中文编辑、发布文案和视觉复核。未接入自动事实核查服务或后台模型 API。只有 URL 的工作流取决于平台允许访问的公开字幕；遇到登录、机器人验证、权限错误立即停止，不绕过。

不下载完整视频，不默认使用封面或第三方人物截图。缺少合法画面时，使用原创文字色块视觉。未找到也未调用 native-subtitle-quote-image；本模块仅兼容 1440×1920、hero_fraction=0.54、font_size=58。上部改为浅色文字主视觉，下部黑底白字和细灰线，不能保证与原 Skill 像素级一致。A 为默认版，B 只在独立目录探索更大的标题；不覆盖 A。

## 使用

Python 3.12、Pillow 12.3.0，中文字体默认 NotoSansCJK；FFmpeg 当前可用但文字工作流不需要。

```bash
cd /workspace/Personal-AI/项目/YouTube商业财经认知卡片
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python pipeline.py acquire 'https://youtu.be/Ktu6nSWtdS0' --out output/新的运行目录
# 如有用户获准使用的文字稿，可加 --transcript /path/transcript.json
# JSON 为 [{"id":"s1","start":12.3,"duration":4.0,"text":"真实原文"}]
# .txt 也可导入，但时间戳记为 null，不推测时间戳。
```

`acquire` 成功取得文字稿返回 0；无文字稿返回 2，保留访问记录并暂停制作；输入或格式错误返回 1。每次使用新目录，保护原素材。字幕自动生成时必须复核人名、数字、专业术语。用户文字稿默认标记为尚未独立核验，不能自动宣称来自视频。

内容编辑完成后：

```bash
.venv/bin/python pipeline.py render --source output/运行目录/source.json --cards output/运行目录/cards.json --out output/运行目录
# B 版单独输出
.venv/bin/python pipeline.py render --source output/运行目录/source.json --cards output/运行目录/cards.json --out output/运行目录/variant-B --variant B
.venv/bin/python -m unittest discover -s tests -v
```

渲染要求恰好首图和正文两张。每条正文含 text、evidence_ids；每张 1～6 条，不凑数。58px 在下部 46% 区域只能容纳有限行数：六条通常须各一行；更长内容宁可减少条数。超出区域立即报错，不静默缩字、裁字或恢复 0.73 主视觉比例。

cards.json 结构见 tests/test_pipeline.py 中的**合成测试数据**；它不是视频内容，也不可发布。证据字段包括 id、kind（author_opinion/fact/editor_analysis/supplement）、segment_id、quote、timestamp、source_url、verification。补充来源还应记录真实公开文献原文与链接，并人工核验；字段存在不表示结论正确。

## 编辑执行规约

1. 先取得足够完整的原文，再按问题明确度 25、信息增量 25、证据质量 25、中文适用性 15、图文适配度 10 评分，每项附理由。≥75 建议做，60～74 人工判断，<60 放弃/换题。内容不足时分数必须为空，不能记 0 分冒充评价。
2. 写出一个核心问题、具体受众、3～8 张完整版建议及逐卡逻辑。首次只做首图和正文；不机械凑六张。
3. 提取原文、秒级时间戳、来源 URL。事实用独立可靠来源核查，观点保留归属；无法核验就标记未核验并降低断言强度。
4. 中文形成问题、原因、机制、案例、方法或判断的自然递进。禁止翻译腔、重复填字、收益承诺、财富焦虑；海外税务/法律/市场案例不可直接套用中国。
5. analysis.md 保存评分理由与结构；cards.json 保存证据和文案；publish.md 保存建议标题、抖音正文、标签及必要来源说明。不可用模板自动生成缺少依据的发布内容。
6. 渲染后打开两张原图和 preview.jpg，检查手机可读性、遮挡、风格、分隔线、字体与内容一致性；在 qa-report.md 补充人工结论。程序几何检查不替代编辑事实核验。
7. 仅删除本运行临时目录内的缓存；不得删除用户素材。大型媒体和 JPG/PNG 默认被本项目 .gitignore 排除；交付文件仍留在工作区，可按需打包下载。没有执行 Git push 或外部发布。
